# Proof Techniques

## 1 Direct Proof

<span style="color:#87A878">**Definition 1.**</span> A direct proof starts from the initial hypotheses and chains logical deductions until the conclusion is reached.

<span style="color:#87A878">**Property 1.**</span> If the hypotheses are true and each step of the reasoning is logically valid, then the conclusion is true.

<span style="color:#808080">*Proof.*</span> A direct proof is a sequence of logical implications. If the initial hypotheses are true and each implication preserves truth, then the final assertion is necessarily true.

<span style="color:#87A878">**Example 1.**</span> If n is even, then n = 2k for some integer k. Then n² = 4k², which is even.



## 2 Proof by Cases

<span style="color:#87A878">**Definition 2.**</span> A proof by cases divides a problem into several possible situations and establishes the property in each case.

<span style="color:#87A878">**Property 2.**</span> If a property holds in all possible cases, then it holds in general.

<span style="color:#808080">*Proof.*</span> The set of cases considered covers all possible situations. Thus, whatever situation is encountered, the property is satisfied, and it therefore holds unconditionally.

<span style="color:#87A878">**Example 2.**</span> For every integer n, n(n + 1) is even. Either n is even, or n + 1 is even; in both cases, the product is even.



## 3 Proof by Contraposition

<span style="color:#87A878">**Definition 3.**</span> A proof by contraposition establishes an implication P ⇒ Q by proving ¬Q ⇒ ¬P.

<span style="color:#87A878">**Property 3.**</span> An implication is logically equivalent to its contrapositive.

<span style="color:#808080">*Proof.*</span> The formulas P ⇒ Q and ¬Q ⇒ ¬P have exactly the same truth values under every interpretation. They are therefore logically equivalent.

<span style="color:#87A878">**Example 3.**</span> If n² is even, then n is even. We prove the contrapositive: if n is odd, then n² is odd.

Suppose n is odd. By definition, there exists an integer k such that n = 2k + 1. Then:

$$n^2 = (2k+1)^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$$

Since 2k² + 2k is an integer, n² = 2m + 1 with m = 2k² + 2k ∈ ℤ. Thus n² is odd.



## 4 Proof by Induction

<span style="color:#87A878">**Definition 4.**</span> Proof by induction establishes a property for every natural number using a base case and an inductive step.

<span style="color:#87A878">**Property 4.**</span> If a property holds for an initial integer and is hereditary, then it holds for every natural number.

<span style="color:#808080">*Proof.*</span> The base case guarantees that the property holds at the start. The inductive step shows that truth is transmitted from n to n + 1. The property therefore holds for every natural number.

<span style="color:#87A878">**Example 4.**</span> For every n ∈ ℕ:

$$1 + 2 + \cdots + n = \frac{n(n+1)}{2}$$

Base case: For n = 1, 1 = 1·(1+1)/2 = 1. The property holds at rank 1.

Inductive step: Suppose the property holds for some n ∈ ℕ, i.e. 1 + 2 + ⋯ + n = n(n+1)/2. Then for n + 1:

$$1 + 2 + \cdots + n + (n+1) = \frac{n(n+1)}{2} + (n+1) = \frac{n(n+1) + 2(n+1)}{2} = \frac{(n+1)(n+2)}{2}$$

The property holds for n + 1. By the principle of induction, it holds for every n ∈ ℕ.



## 5 Proof by Contradiction

<span style="color:#87A878">**Definition 5.**</span> A proof by contradiction assumes the negation of a proposition and shows that this assumption leads to a contradiction.

<span style="color:#87A878">**Property 5.**</span> If the negation of a proposition leads to a contradiction, then the proposition is true.

<span style="color:#808080">*Proof.*</span> A contradiction means the initial hypothesis is impossible. Since the negation of the proposition is false, the proposition itself is true.

<span style="color:#87A878">**Example 5.**</span> There are infinitely many prime numbers.

Suppose, for contradiction, that there exists a largest prime number, denoted pₘₐₓ. Then the list of all primes would be finite: p₁ = 2, p₂ = 3, …, pₘₐₓ.

Consider the number N = p₁ p₂ ⋯ pₘₐₓ + 1. By construction, N is greater than all existing primes. Moreover, N is not divisible by any pᵢ, since dividing N by pᵢ leaves a remainder of 1.

Thus N is either prime, or divisible by a prime not in our list, which contradicts the existence of a largest prime.
